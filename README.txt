20 WEBSITE TEMPLATES

Open index.html to browse all twenty.

Each folder is a self-contained site:
  index.html     home
  about.html     about / story
  services.html  services, menu, listings, portfolio or tour dates
  contact.html   contact details and form
  style.css      all styling; colors, fonts and shapes are variables at the top

To customize
- Colors, fonts, corner radius: edit the :root block at the top of style.css.
- Images: the patterned blocks with class "art" are placeholders. Replace each
  with an <img> tag, or set a background-image on it.
- Fonts load from Google Fonts (open licences). Change the <link> in each
  page's <head> and the --display / --body variables to swap them.
- Forms post to "#". Point the action at your own form handler.
- All names, people, prices, reviews and contact details are invented
  placeholder copy. Replace them with real content before publishing.
